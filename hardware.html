Componentes de Computadores e Grandezas Elétricas

1.1 Componentes Internos

1.1.1 CPU

A CPU (Unidade Central de Processamento) é o cérebro do computador, responsável por executar instruções e cálculos.

1.1.2 Armazenamento

O armazenamento é onde os dados do computador são mantidos, podendo ser HDD ou SSD.

1.1.3 Memória

A memória RAM é usada para armazenar dados temporários enquanto o computador está em uso.

1.1.4 Fonte de alimentação

A fonte de alimentação converte energia elétrica para alimentar os componentes do computador.

1.2 Componentes Externos

1.2.1 Teclado

O teclado é um periférico de entrada que permite a digitação de caracteres e comandos.

1.2.2 Monitor de vídeo

O monitor exibe as imagens e gráficos gerados pelo computador.

2. GRANDEZAS ELÉTRICAS

2.1 Potência elétrica

A potência elétrica mede a quantidade de energia transferida ou convertida por unidade de tempo.

2.2 Tensão elétrica

A tensão elétrica é a diferença de potencial entre dois pontos, sendo medida em volts.

2.3 Corrente elétrica

A corrente elétrica é o fluxo de elétrons através de um condutor.
